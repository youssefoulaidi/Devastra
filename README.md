# QuranPro — القرآن الكريم صوتًا وصورةً وقراءةً 📖🎧

تطبيق أندرويد **مجاني ومفتوح المصدر** للقرآن الكريم: استماع، مشاهدة، قراءة، بث مباشر،
إذاعات، وتفسير صوتي — بأصوات أكثر من **150 قارئًا**.

A **free & open-source** Android app for the Holy Quran: audio, video, reading,
live TV, radios and audio tafsir — with **150+ reciters**.

## 🆕 آخر الإصلاحات / Latest fixes (v1.6)

| المشكلة | الإصلاح |
|---|---|
| 🕰️ **الفجر والشروق يُحسبان في اليوم التالي (دون إنترنت)** | الحساب الفلكي على الجهاز كان يلفّ الساعات إلى `0..24` عند التحويل إلى UTC، فتنتقل الصلوات المبكرة يومًا كاملًا إلى الأمام شرق خط غرينتش (طوكيو، جاكرتا، كوالالمبور، سيدني…) وتنتقل العشاء يومًا إلى الخلف غربًا (نيويورك…). النتيجة: عدّاد «الصلاة القادمة» يختار الصلاة الخطأ، وأذان الفجر لليوم لا يُجدول إطلاقًا. أصبح التحويل بلا لفّ — تحقّقنا من 16 مدينة × 73 يومًا: **567 حالة خاطئة → 0** |
| 🔢 **التطبيق يعرض رقم إصدار قديم** | رقم الإصدار كان مكتوبًا يدويًا في 9 مواضع (`1.0` في شاشة «اتصل بنا» و6 طلبات شبكة، `1.3` في الإعدادات، `1.5` في المُحمِّلات). أصبح مصدرًا واحدًا يُقرأ من الحزمة المثبّتة عبر `App.versionName()` / `App.userAgent()`، فلا يتقادم مع كل إصدار |
| 🌐 **اسم السورة بالعربية في إشعار التشغيل للغة الإنجليزية** | عنوان المقطع كان `"سورة " + الاسم` مكتوبًا يدويًا فيظهر في إشعار الوسائط وشاشة القفل حتى مع اختيار English. أصبح يستخدم `R.string.read_title` الموطّن («سورة %1$s» / «Surah %1$s») مثل بقية التطبيق، وكذلك عنوان التفسير الصوتي |
| 🎧 **الملفات المحمّلة لا تعمل دون إنترنت** | كان مشغّل الصوت يستخدم `DefaultHttpDataSource` وهو لا يقرأ `file://`، فيفشل تشغيل الملفات المحمّلة. أصبح المشغّل يستخدم `DefaultDataSource` (يقرأ المحلي والشبكة) مع تحويل تلقائي بين الملف المحلي والبث عند أي خطأ. **v1.6:** إضافة فحص `AudioCheck.looksLikeAudio` وتجربة قسرية للملف المحلي قبل إظهار خطأ الشبكة، وإخفاء رسالة "لا يوجد إنترنت" عند وجود ملف محلي |
| ⬇️ **فشل بعض التحميلات** | التخزين انتقل إلى مساحة التطبيق الداخلية (لا تُفصل ولا يمسحها النظام)، مع استكمال التحميل المتوقف (HTTP Range)، وإعادة المحاولة، والتحقق من أن الملف صوت حقيقي، ودعم السور الكبيرة (حتى 512MB) |
| 🕌 **الأذان لا يعمل دون إنترنت** | 5 أصوات أذان مدمجة في التطبيق (مكة، العبدالباسط، رفعت، المنشاوي، صهيب) + إمكانية **تحميل أي صوت** للاستخدام دون إنترنت من إعدادات المؤذن، ويُحفظ في مساحة دائمة. وعند تعذّر الصوت يعمل نغمة التنبيه بدل الصمت. **v1.6:** زر التجربة الآن يعمل بث مباشر إذا لم يكن الصوت محملاً بعد (مع تحميله في الخلفية)، ويعود للمحلي عند فشل البث |
| 🕰️ **مواقيت الصلاة دون إنترنت** | حساب فلكي على الجهاز لنفس طرق الحساب والمذهب (الجمهور/الحنفي) يعمل عند انقطاع الشبكة، وجدولة أذان الغد أيضًا |
| 📚 **التفاسير فارغة** | استجابة واجهة التفاسير هي `tafasir.soar[]` بينما كان المحلّل يبحث عن `sora` ككائن، فكانت القائمة تظهر فارغة. تم إصلاح التحليل ودعم الشكل القديم، مع عرض تفسير كل مقطع وتخزينه للعمل دون إنترنت |
| 🎨 **ألوان إضافية** | **جديد v1.6:** 6 ثيمات ألوان (أخضر زمردي افتراضي، أزرق، بني، بنفسجي، تركوازي، أحمر) يمكن تغييرها من الإعدادات، مع دعم الوضع الليلي لكل لون |
| 🖼️ **أيقونة YSAH-DEV** | أيقونة اللانشر في `mipmap` تحتوي YSAH-DEV، وتم تحديث شاشات البداية والقائمة الجانبية والمشغل لاستخدام نفس الأيقونة |

## 🧱 بنية المشروع / Project structure

```
app/src/main/java/com/quranpro/app/
├── App.java                 # نقطة التطبيق
├── audio/                   # Media3: PlayerService, PlayerManager, Track
├── data/                    # Api, Models, QuranMeta, Store (SharedPreferences)
├── pray/                   # مواقيت الصلاة والأذان: جدولة التنبيهات، صوت المؤذن، الإشعارات
├── ui/                     # Activities + Fragments (السور، القرّاء، الفيديو، البث، القبلة، المواقيت…)
└── util/                   # DownloadHelper, ImageLoader, Ui
app/src/main/assets/fonts/   # Amiri + Amiri Quran (الرسم العثماني)
```

- **الحزمة:** `com.quranpro.app` · **اللغة:** Java 17
- **الاعتماديات:** AndroidX AppCompat/Material3/RecyclerView/DrawerLayout · Media3 (ExoPlayer + HLS + Session) · Gson

## 🛠️ البناء / Build

```bash
# يتطلب JDK 17 + Android SDK 34
./gradlew assembleDebug
# APK في: app/build/outputs/apk/debug/app-debug.apk

./gradlew assembleRelease
# (موقّع فقط عند وجود keystore.properties — انظر RELEASE.md)
```

- minSdk 24 (أندرويد 7.0+) — targetSdk 34
- Java + Media3 (ExoPlayer) + Material3
- يُبنى تلقائيًا عبر GitHub Actions عند الدفع إلى `main`،
  ويُنتج **GitHub Release** بملفات APK — انظر [`RELEASE.md`](RELEASE.md)
